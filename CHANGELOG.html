Přehled změn Rooku

Nevydaná verze

Nové funkce

  • Připojení ke vzdálené relaci přes SSH pomocí rook attach [session] --remote user@host; unixové sockety Rooku zůstávají bezpečně na vzdáleném počítači.
  • Správa relací: rook status, rook reload, rook delete a jmenný prostor rook session.
  • Bezpečnější automatizace panelů: odeslání doslovného textu, kláves nebo příkazu; inspekce panelu, hledání souseda, přesun mezi záložkami a čekání na výstup pomocí textu či regulárního výrazu.
  • Vyhodnocení a povýšení výsledků fan-outu: porovnání commitů kandidátů, výpis patche a bezpečný fast-forward čistého vítězného řešení.
  • rook agents explain <panel> vysvětluje, proč detekce zvolila aktuální stav agenta, včetně vítězného pravidla a vstupních signálů.
  • Doplňování příkazů pro Bash a Zsh: source <(rook completion bash) nebo source <(rook completion zsh).
  • Rozšířená podpora kláves pro agentní TUI: modifikované navigační a editační klávesy i F1–F12 ve formátu kompatibilním s xtermem.
  • Průvodce prvotním nastavením integrací pro Claude Code, Codex CLI a OpenCode.

Změny

  • Byl odstraněn manager bar a zvláštní mechanismus manager agenta; spolehlivé frontování vstupu zůstává běžnou vlastností panelů.
  • README a přibalená instrukce pro agenty nyní odpovídají aktuálním příkazům.
